## Tag types

The kinds of tags. Each type has a color and a place in the order types appear in sidebars, panels and the directory.

- Rename a type in its box, pick its **color**, and move it **▲ ▼**.
- The **default** type is the one new tags get, unless written as `type:name` (the key shown next to the name).
- A type can be deleted only once it has no tags, and never while it's the default.

### Custom fields

The **Custom fields** tab defines the info fields every tag of a type gets on its wiki page. Pick a type on the left.

- **+ Add field**, then name it. Move fields with **▲ ▼**; **Filled on** shows how many of the type's tags have a value.
- **Kinds:** text, long text, number, date, link, choice, image, tag reference.
- **Settings ▾:** a choice's options, a number's unit, which types a tag reference allows and whether it takes several tags (in order).
- **Changing the kind** keeps every value that converts. The menu shows the cost of each kind; when some values would be cleared, you're asked first.
- **Delete** asks first — the field's values go with it.
