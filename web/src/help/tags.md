## Tags

Every tag in your library, grouped by type, with how many images use each.

- **Filter** by name or alias, **sort** by name or by use, and show one type at a time.
- Click a tag to see its images; **Ctrl + click** (or right-click) to edit it.
- Select tags with their boxes to **merge** them (pick the one that stays; the others can become its aliases) or **delete** them (they come off every image; the images stay).
- **+ New tag** creates a tag before using it — of the default type, or written as `type:name`.
- **Tag types →** manages the kinds of tags.
