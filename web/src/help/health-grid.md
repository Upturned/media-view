## Untagged images · grid

The untagged images (outside the Inbox) as a grid. It's a view, not a folder: each image stays in its album.

- Filter by album with the chips, or to the **NEW** ones (arrived from outside the app).
- Select images and use **# Tags…** to tag them in bulk, **Mark as seen** or **Leave untagged**.
- Tagged images stay in place, dimmed, so the grid doesn't jump — **↻ Refresh** takes them out.
- Open an image: ← → stay inside this view.
