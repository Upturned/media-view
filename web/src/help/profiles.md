## Profiles

Several people can share a library, each with their own **profile**: their own stars (Favorites), grid and slideshow settings, theme, and the tags that are *them*. Images, tags, the wiki and collections are shared by everyone.

- Click a profile to open it. A profile with a **password** (🔒) asks for it first.
- **+ New profile** makes one: a name, and a password if you want one.
- This page shows when media-view starts and no profile is chosen yet (several profiles, or a password), and from **Switch profile…** in the profile menu (your picture at the right end of the top bar).
- A password keeps others from using media-view as you. It doesn't hide your images: anyone with access to this computer can still open the library folder.
- **Forgot a password?** Run `reset-password.bat` next to `start.bat` (or `npm run profile:reset-password` from the app folder): it clears the password of the profile you name.
- **Keyboard:** the arrows move between the cards; Enter opens one.
