Why white. Hover and current own the accent, selection owns accent2. The ring is the only state in text colour, the only one that is 2 px, and the only one that stands off the element. Three axes apart — colour, weight, position — so it never reads as hover or selection.
Why the dark gap. The 3 px bg2 band between element and ring keeps it readable on any content — a bright cover, a yellow selection ring, a white-filled segment, an accent button.
No motion. Appears and moves instantly; it's a cursor, not a highlight.

  outline-offset: 2px;

RESUMESNext key moves from the remembered item, not the hovered one (Explorer). Clicks and opening an image update the remembered item; hover never does. Back from the viewer: lands on the image you were on. FIRST KEYWith nothing remembered yet, the first arrow lands on the first item instead of moving.
